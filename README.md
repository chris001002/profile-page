# codewithchris.my.id

Personal portfolio for Christian — Full-Stack Engineer (React / React Native, Django REST, LangGraph).

## Scripts

- `npm start` — dev server at http://localhost:3000
- `npm run build` — production bundle in `build/`
- `npm run deploy` — publish `build/` to the `gh-pages` branch

## CV

The one-page CV served at `/raw/CV Christian.pdf` lives in `public/raw/`. Replace that file (keep the name, `Contact.js` and `Home.js` hardcode it) whenever the CV changes.
